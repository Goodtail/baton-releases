# Baton Releases

Public distribution metadata and signed release assets for Baton.

- Install Baton from the DMG attached to the latest GitHub Release.
- `appcast.xml` is the Sparkle update feed.
- `policy.json` is the minimum supported build policy.
- GitHub-generated “Source code” archives contain only this release metadata; they are not the Baton application source and should not be used for installation.
